Scoped to config, not code

What she can change.

Same whitelisted-action pattern. No arbitrary SQL. Every change gets a diff preview and an audit note.

Plans

Create, price, duration, FUP thresholds, activate/deactivate, hide/show per book.

Price books

New books, plan overrides, reseller assignments, visibility toggles.

Dunning rules

Grace thresholds, notification cadence, per-plan overrides.

Tenants (WaaS)

Onboard, SSID mapping, brand tokens, default plan.

NAS devices

Register, secret rotation, threshold overrides, device class assignment.

Notifications

SMS/email templates per tenant, escalation routing, quiet hours.
Every change is reversible

Diff in. Diff out. Always.

Every config change Mira applies is logged with its reverse-diff, so undo is one click. If Beach Day turns out to be a bad idea by Friday afternoon, "Mira, roll back the Beach Day plan" gets you back to Thursday morning.
